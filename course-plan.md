## Resumen del Curso

Este curso introduce a estudiantes de secundaria a los fundamentos de programación con Java. El contenido está pensado para estudiantes de 12 a 17 años sin experiencia previa en programación.

El curso explica los conceptos de forma progresiva, usando ejemplos simples, prácticas guiadas y editores en línea. No se requiere instalar ninguna herramienta. Todo puede desarrollarse desde un navegador web.

**Duración total:** aproximadamente 60 minutos  
**Público objetivo:** estudiantes de 12 a 17 años sin experiencia previa en programación  
**Prerrequisitos:** ninguno  
**Herramientas necesarias:** navegador web moderno  
**Repositorio de código fuente:** pendiente  
**Videos:** pendientes  

## Objetivo general

Lograr que el estudiante comprenda los fundamentos de Java y pueda construir un programa sencillo usando variables, decisiones, bucles, métodos, clases y objetos.

## Objetivos específicos

Al finalizar el curso, el estudiante será capaz de:

- Explicar qué es programar y para qué sirve Java.
- Ejecutar un primer programa en Java usando un editor en línea.
- Declarar variables y usar tipos de datos básicos.
- Aplicar operadores y expresiones simples.
- Usar estructuras de control como `if`, `else`, `for` y `while`.
- Crear métodos con parámetros.
- Leer datos básicos desde consola.
- Crear clases y objetos.
- Aplicar encapsulación usando atributos privados y métodos públicos.
- Construir un programa simple basado en programación orientada a objetos.

## Secuencia de lecciones

### Lección 1: ¿Qué es Java y qué es programar?

**Duración estimada:** 6 minutos  
**Tema principal:** introducción a la programación y primer programa en Java.  
**Video:** pendiente  
**Práctica online:** pendiente  
**Archivo inicial:** `starter-files/lesson-01-hello-world/Main.java`  
**Ejemplo completo:** `completed-examples/lesson-01-hello-world/Main.java`

#### Descripción

En esta lección el estudiante conoce qué es programar, qué es Java y cómo se ve un programa simple. La idea es presentar la programación como una forma de dar instrucciones claras a una computadora.

#### Resultado esperado

El estudiante entiende qué es un programa y ejecuta su primer mensaje en consola usando Java.

#### Conceptos clave

- Programa
- Instrucción
- Consola
- Método `main`
- `System.out.println`

---

### Lección 2: Variables, tipos de datos y operadores

**Duración estimada:** 9 minutos  
**Tema principal:** almacenamiento de datos y operaciones simples.  
**Video:** pendiente  
**Práctica online:** pendiente  
**Archivo inicial:** `starter-files/lesson-02-variables-types/Main.java`  
**Ejemplo completo:** `completed-examples/lesson-02-variables-types/Main.java`

#### Descripción

En esta lección el estudiante aprende a guardar información usando variables. Se explican tipos de datos básicos como `String`, `int`, `double` y `boolean`.

- Tipos de datos
- Texto
- Números enteros
- Números decimales
- Valores verdadero/falso
- Concatenación
